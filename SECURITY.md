# Security and Privacy Policy

TrustCXR is a private research repository. The supported release is `v1.0.0-research`, a Windows-scoped, research-only system.

## Reporting an issue

Contact the repository owner privately through an available authorized channel. Do not open a public issue containing sensitive information.

## Sensitive-data policy

Never commit or upload patient identifiers, PHI, real patient images, raw DICOM metadata, credentials, API keys, tokens, private keys, local secrets, or restricted dataset samples. Do not include such material in screenshots, logs, fixtures, pull requests, or issue reports.

Raw datasets and accepted checkpoints remain local and intentionally untracked. Temporary uploads must be request-scoped and cleaned. The UI performs no external upload, telemetry, or browser persistence.

## Repository handling

Keep the repository private. Security and privacy fixes must preserve the frozen scientific contracts and must not expose internal paths, UIDs, stack traces, or raw metadata through the API or UI.
