# Stage 13C Patient-Safe Multi-View Pair Design

Stage 13C creates local pair-design records only within explicitly resolved studies. An eligible pair requires exactly one AP/PA frontal record and exactly one LATERAL record in the same study and split.

Single-view studies remain supported as explicit dispositions. Studies containing duplicate, ambiguous, or `UNKNOWN` views remain unpaired. `OTHER` stays withheld. The stage performs no image access, heuristic selection, inference, training, or locked-test access.
