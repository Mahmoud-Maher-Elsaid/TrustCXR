# Stage 12D Input-Rejection Candidate Adjudication

Adjudication follows the mutually exclusive protocol 1.0.0 taxonomy. File integrity, trusted CheXpert metadata, image geometry, and direct boundary review are recorded separately. Visual appearance supports but never independently determines a label.

Valid trusted lateral radiographs cannot become incomplete-anatomy examples solely because of portrait geometry. Incomplete anatomy requires material absence of required thoracic anatomy at the image boundary. A technically valid, fully decodable near-blank JPEG is inadequate quality when objective brightness and contrast measurements show unusable content; it is not corrupt input without evidence of malformed file or pixel data.

The patient-level adjudication CSV and missing-slot summary remain ignored under the Stage 12D manual package. The final annotation CSV is hash-checked unchanged.
