`SYNTHETICALLY_VALIDATED_LOCAL_RESEARCH_UI_EXPERT_REVIEW_REQUIRED`. Acceptance does not
authorize real images, generic DICOM viewing, overlays, model loading, inference, GPU
profiling, patient processing, persistent services, clinical use, or language-model work.

semantics, PNG/JPEG synthetic viewer contract, DICOM and overlay holds, research-only scores,
predictive uncertainty terminology, verifier states, DEFER-first decisions, sanitized failure
semantics, browser privacy, injection safety, accessibility, and deterministic cleanup.

only and does not activate DICOM viewing, real images, models, inference, patients, GPU
profiling, or LLM work. No LLM-authorized gate is scheduled.
