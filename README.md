# TrustCXR

Evidence-Grounded, Uncertainty-Aware Vision-Language System for Chest X-Ray
Analysis and Report Verification.

## Project goal

TrustCXR is a modular medical artificial intelligence research system for:

- Chest X-ray quality and view assessment
- Multi-label abnormality classification
- Anatomical segmentation
- Lesion segmentation
- Abnormality detection and localization
- Uncertainty estimation
- Out-of-distribution detection
- Evidence-grounded report generation
- Radiology report verification
- Accept, revise, or defer decision support

## Safety scope

TrustCXR is a research project.

Its outputs are not medical diagnoses and must not replace qualified clinical
judgment.

## Local data policy

All datasets remain local at:

`F:\AI\TrustCXR\TrustCXR-Data`

Datasets, medical images, radiology reports, model checkpoints, credentials,
and patient-level outputs must never be committed to Git or uploaded to GitHub.
