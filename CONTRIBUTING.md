# Contributing

## Branches

- `main`: stable and reviewed code
- `develop`: integration branch
- `feature/<name>`: feature development
- `fix/<name>`: bug fixes

## Prohibited commits

Never commit:

- Datasets
- Medical images
- Patient-level reports
- Credentials
- Secrets
- Model checkpoints
- Large generated outputs

## Validation

All changes must pass the project tests and static checks before merging.
